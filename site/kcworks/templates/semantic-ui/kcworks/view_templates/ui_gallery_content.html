Emphasis & semantic colors

Primary block + color variants in button.overrides. Ring colors are CSS vars on .ui.button (--button-ring-color / --button-ring-color-hover); variants override those vars. Chrome concerns are separate and compose: .transparent (upstream: bg, padding 0), .padded (compose with .transparent to restore SUI padding via --button-padding), .borderless (resting border; hover ring restored via the CSS var), .borderless-hover (no border on hover either). Example: .transparent.padded.
